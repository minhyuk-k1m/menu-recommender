# 🍽️ 오늘 뭐 먹지? (Today's Menu Recommender)

매일 반복되는 식사 메뉴 고민을 해결해주는 질문 & 상황 기반 맞춤형 메뉴 추천 웹 서비스입니다.

![썸네일](./thumbnail.jpg)

---

## ✨ 주요 기능 및 특징

- **🍱 3가지 추천 모드 지원**:
  - **일반 모드**: 취향과 기분에 맞춘 일상 식사 메뉴 추천
  - **다이어트 모드**: 저칼로리 & 고단백, 식단 관리와 체중 조절에 좋은 다이어트 메뉴
  - **건강 / 회복식 모드**: 아프거나 속이 불편할 때 소화가 잘 되고 부담 없는 힐링 메뉴
- **⭐ 5점 만점 평가 & AI 자가 학습 (Self-Learning)**:
  - 추천 결과 화면에서 별점(1~5점)을 남기면 브라우저(`localStorage`)의 AI 학습 모델이 사용자의 음식 취향(메뉴, 카테고리, 맛, 형태 등)을 지속적으로 학습합니다.
  - 별점 4~5점을 받은 메뉴 및 유사 카테고리는 가중치가 증가하여 다음 추천 시 `🤖 AI 취향저격` 뱃지와 함께 우선 추천됩니다.
  - 별점 1~2점을 받은 비선호 메뉴는 가중치를 차감하여 추천 빈도를 낮춥니다.
- **📍 실시간 위치 기반 날씨 자동 감지**:
  - 사용자 위치의 실시간 기온 및 기상 상태(맑음, 비, 추움, 더움 등)를 자동 분석하여 날씨에 어울리는 음식을 추천에 자동 반영합니다.
- **🎯 최적화된 8문항 질문 Flow**:
  - Q1. 성별 (남성 / 여성)
  - Q2. 식사 시간대 (아침 / 점심 / 저녁 / 야식·간식)
  - Q3. 현재 기분 (스트레스 / 활력 / 평범 / 위로)
  - Q4. 배고픔 정도 (매우 배고픔 ~ 입이 심심함)
  - Q5. 끌리는 맛 (매콤 / 담백 / 달콤 / 새콤 / 짭짤 / **🤔 잘 모르겠어요**)
  - Q6. 음식 형태 (국물 / 밥 / 면 / 단백질·고기 / 가벼운 음식)
  - Q7. 식사 인원 (혼밥 / 2인 / 단체 / 직장 동료)
  - Q8. 예산 (2만원 이내 / 2~5만원 / 5~10만원 / 10만원 이상)
- **📤 대화방 메신저 간편 공유**:
  - X, Facebook, 카카오톡, Instagram, 링크/텍스트 복사 등을 지원하여 친구 및 지인들과 결과를 손쉽게 공유할 수 있습니다.

## 🛠️ 기술 스택

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS)
- **AI & Storage**: Client-side Preference Reinforcement Learning via `localStorage`
- **API**: Open-Meteo Weather API & Web Geolocation API
- **Deployment**: Standalone Single-page Web Application
