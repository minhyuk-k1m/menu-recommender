# 🍽️ 오늘 뭐 먹지? (Today's Menu Recommender)

매일 반복되는 식사 메뉴 고민을 해결해주는 질문 기반 맞춤형 메뉴 추천 웹 서비스입니다.

![썸네일](./thumbnail.jpg)

---

## ✨ 주요 기능

- **🎯 맞춤형 9문항 질문 Flow**: 식사 시간대, 날씨, 기분, 성별, 배고픔 정도, 선호하는 맛, 음식 형태, 인원, 예산 등을 분석하여 최적의 메뉴를 도출합니다.
- **📊 가중치 기반 추천 엔진**: 사용자 답변의 핵심 변수(맛, 음식 형태 등)에 가중치를 부여하여 가장 어울리는 상위 TOP 3 메뉴와 매칭률(%)을 제공합니다.
- **💡 추천 이유 및 답변 요약**: 선택한 답변에 기반한 자연스러운 추천 사유와 요약 태그를 함께 보여줍니다.
- **📤 다양한 대화방 공유**: X(Twitter), Facebook Messenger, 카카오톡, Instagram, 링크/텍스트 복사 등 지인들과 메뉴 추천 결과를 메신저로 간편하게 공유할 수 있습니다.
- **📱 반응형 웹 & 감성적 UI**: 부드러운 애니메이션과 따뜻한 코랄/피치 그라디언트 기반의 모바일 친화적 인터페이스.

---

## 🛠️ 기술 스택

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS)
- **Deployment**: Standalone Single-page Application (별도의 백엔드/빌드 설정 없이 즉시 실행 가능)

---

## 🚀 실행 방법

1. 본 레포지토리를 클론합니다:
   ```bash
   git clone https://github.com/MINHYUK-KIM/today-menu.git
   ```
2. `index.html` 파일을 웹 브라우저에서 실행합니다.
